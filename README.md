# IC Buddy

เว็บแอปติวสอบ **IC Plain (P1)** รูปแบบคล้ายอินสตาแกรม: ฟีดข้อสอบ, สตอรี่สูตร, บทเรียน, เกม และสำรองความคืบหน้าด้วยรหัส

- 90 ข้อสอบ · 22 บท · สูตรและชีตสรุป
- โทนดำ / โทนขาว
- สำรองและกู้ความคืบหน้าด้วยรหัส `ICB1.`
- รูปมาสคอตประกอบ ไม่มีรูปหรือเพลงศิลปิน
